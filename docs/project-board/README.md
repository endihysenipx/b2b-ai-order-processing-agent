# Project Board

Equivalent board for Week 3 when a hosted GitHub Project is not available from the local environment.

## Columns

- Backlog
- Ready
- In Progress
- Code Review
- Testing
- Done

## Labels

`frontend`, `backend`, `database`, `ai`, `ocr`, `email`, `xml`, `documentation`, `testing`, `infrastructure`, `bug`, `enhancement`, `priority-high`, `priority-medium`, `priority-low`, `week-3`, `future`

## Milestones

- Week 3 - Foundation
- Sprint 2 - AI and Document Processing
- Sprint 3 - Human Review and XML
- Final Integration and Testing

See `docs/project-board/week-3-issues.md` for backlog cards and team allocation.
